# Homebrew Tap

Homebrew formulae maintained by Ziyan Junaideen.

## Installation

Add and trust the tap once:

```sh
brew tap ziyan-junaideen/tap
brew trust ziyan-junaideen/tap
```

Install the JDeen CLI:

```sh
brew install ziyan-junaideen/tap/jdeen-cli
jdeen --version
```

Install the Edge CLI:

```sh
brew install ziyan-junaideen/tap/edge-cli
edge --version
```
